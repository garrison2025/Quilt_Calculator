## Scope controls

- Bias binding, diagonal quilt backing, rag quilt, mitered border and square-in-a-square specialty geometry are not claimed complete.
- WOF area equivalence alone is not a purchase calculator and has no indexable page.
- These are feasible nonoverlapping cut layouts, not guaranteed globally optimal nesting.
- Distinct fabric SKUs are never silently combined in one roll.
- One-piece batting is explicitly distinguished from pieced backing.
- An output is not a printed 1:1 sewing pattern.
